Reasoning given: **Change summary** – The `deficit` function assumes the column can deal damage for only the number of rounds the current front pirate has before reaching position 3 (`steps = MAX_POSITION - front.position`). This is too pessimistic when there are several pirates stacked: if we kill the front early we can keep shooting the column for as many rounds as the *farthest‑back* pirate needs to reach 3.
